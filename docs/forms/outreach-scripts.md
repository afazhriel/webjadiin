# OUTREACH SCRIPTS (Fill-in) — Hafi Digital

Ganti semua `[...]` sebelum kirim. Aturan: **PERSONAL · SHORT · SPECIFIC · LOW PRESSURE.**
CTA awal selalu: *"Kalau berkenan, saya bisa kirim audit singkat."* Jangan langsung jual paket.

---

## PRA-OUTREACH (isi dulu)
```
Nama Bisnis        : ______________________________________
Nama orang (jika tahu) : __________________________________
Kategori           : ______________________________________
Kota               : ______________________________________
Observasi spesifik : ______________________________________
Dampak bisnis      : ______________________________________
Personalization 1–3 : ______________________________________
```

---

## A. WHATSAPP

**Struktur:** Greeting + Context + Specific observation + Value + Soft CTA.

```
Halo Pak/Bu [Nama], saya menemukan [Nama Bisnis] saat mencari
[kategori] di [kota].

Saya lihat bisnisnya sudah aktif, tetapi website-nya belum banyak
membantu calon pelanggan memahami [masalah spesifik].

Saya membantu bisnis memperbaiki hal seperti ini. Kalau berkenan,
saya bisa kirim audit singkat 3 poin untuk website [Nama Bisnis] —
tanpa biaya.

Boleh saya kirimkan?
```

**Kalau dijawab "boleh":**
```
Terima kasih, Pak/Bu [Nama]. Ini 3 poinnya:

1. [Temuan 1 — observasi + dampak]
2. [Temuan 2 — observasi + dampak]
3. [Temuan 3 — observasi + dampak]

Kira-kira bagian mana yang paling ingin dibenahi lebih dulu?
```

---

## B. INSTAGRAM DM

Lebih pendek. Tujuan: **GET REPLY**.

```
Halo Kak, saya menemukan [Nama Bisnis] dari Instagram 🙌

Saya lihat [observasi spesifik], padahal [dampak singkat yang masuk akal].

Saya kebetulan mengerjakan website untuk bisnis dan melihat ada
peluang untuk memperjelas [area spesifik].

Kalau berkenan, saya bisa kirim 3 poin audit singkatnya. Boleh?
```

---

## C. EMAIL

**Subject:** `Sedikit masukan untuk website [Nama Bisnis]`

```
Halo [Nama],

Saya [Nama] dari Hafi Digital. Saya menemukan [Nama Bisnis] saat
mencari [kategori] di [kota].

Saya perhatikan [observasi spesifik]. Bagi calon pelanggan, ini bisa
membuat [dampak bisnis relevan].

Kami membantu bisnis memperbaiki hal seperti ini. Saya sudah
menyiapkan audit singkat 3 poin untuk website Anda — tanpa biaya.

Kalau berkenan, cukup balas "Kirim".

Terima kasih,
[Nama] — Hafi Digital
```

## D. FOLLOW-UP (maks. 3, lalu berhenti)

**FU #1 — check-in (2–3 hari):**
```
Halo Pak/Bu [Nama], saya follow up terkait pembahasan website
[Nama Bisnis]. Kalau ada yang ingin ditanyakan, saya siap bantu.
```

**FU #2 — value tambahan:**
```
Halo Pak/Bu [Nama], sekadar berbagi: [insight/contoh relevan singkat].
Kalau perlu, saya bisa sesuaikan dengan prioritas Anda.
```

**FU #3 — close the loop:**
```
Halo Pak/Bu, saya follow up terkait pembahasan website [Business].
Kalau masih dipertimbangkan, saya bisa bantu breakdown scope-nya
supaya lebih mudah disesuaikan dengan kebutuhan. Kalau belum jadi
prioritas sekarang, tidak masalah.
```
